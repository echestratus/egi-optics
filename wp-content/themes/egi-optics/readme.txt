Custom block theme for egi-optics.com (PT EGI Optik Indonesia).

== Description ==

A dark, precision-engineered block theme for a laser and electro-optical defense company.

* Design tokens in theme.json (palette, fluid type scale, spacing, shadows, gradients).
* Self-hosted variable fonts: Space Grotesk (headings), DM Sans (body), JetBrains Mono (labels and spec values). SIL Open Font License; see assets/fonts/README.md.
* Templates for the Products post type provided by the EGI Optics Core plugin (archive, category, single).
* Patterns: hero, stats strip, company intro, competencies, why EGI, vision and mission, products grid, product body, field-trial video, downloads, latest news, contact cards, call to action, full Home/About/Contact pages.
* Block styles: spec table, check list, square bullets, tag chips, outline and ghost buttons, card and panel groups, engineering image frame, glow separator.
* Navigation menus are resolved by slug (wp_navigation posts named "primary" and "footer"), so template parts contain no environment-specific IDs.

== Requirements ==

The EGI Optics Core plugin must be active for products, product meta and the `egi/site` block bindings.
